# Install KV Archive v0.16.7

## Fresh installation

1. Extract `KV-Archive-v0.16.7-extension-install.zip`.
2. Open `chrome://extensions` and enable Developer mode.
3. Select **Load unpacked**.
4. Choose the extracted folder whose root directly contains `manifest.json`.
5. Confirm the extension version is `0.16.7`.

## Upgrade while preserving browser-local data

1. Close open KV Archive pages.
2. Back up the currently loaded extension folder.
3. Replace its files with the extracted v0.16.7 files while keeping the same folder path.
4. Click **Reload** on `chrome://extensions`.
5. Confirm version `0.16.7`, then test both Light and Dark appearance.

No database migration is introduced in this release.
