# KV Archive v0.13.3 Changeset

## Routing

- Added one shared `isStructuredChatGPTConversationUrl()` rule.
- Recognizes `/c/{conversationId}` at any valid ChatGPT path depth.
- Popup and background no longer disagree about Project/GPT conversation routes.
- Added nested ChatGPT route regression tests.

## DOM history hydration

- Added gradual upward scrolling with bounded iterations and stable-at-top detection.
- Finds the actual scrollable ancestor of rendered conversation messages.
- Captures overlapping DOM windows while history loads.
- Merges virtualized windows by suffix/prefix overlap and stable message IDs.
- Preserves identical text from distinct turns.
- Restores the approximate original reading position after capture.
- Applies the same bounded hydration mechanism to other user-triggered visible-only AI pages.

## Capture arbitration

- A verified authoritative ChatGPT response remains the preferred source.
- Unverified debugger results are compared with hydrated DOM results.
- The larger readable branch is selected when DOM hydration exposes more content.
- DOM-selected results remain `PARTIAL` and include a `HYDRATED_DOM_SELECTED` warning.

## Diagnostics

- Added renderer-level active-path diagnostics.
- Added A/B/C/D pipeline counts to capture metadata and integrity reports.
- Readable HTML exposes the counts in a collapsed diagnostic panel.
- Popup status explains that the page may automatically scroll upward.

## Tests

Added regression coverage for:

- ordinary and nested Project/GPT ChatGPT conversation URLs;
- conversation-ID extraction from nested paths;
- four overlapping virtualized windows totaling 50 messages;
- repeated identical text with distinct stable turn IDs;
- hydrated fallback wiring and larger-branch arbitration;
- A-to-D diagnostic rendering.
