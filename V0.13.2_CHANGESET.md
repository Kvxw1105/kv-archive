# KV Archive v0.13.2 Changeset

## Capture

- Current ChatGPT export prefers the authenticated authoritative conversation endpoint.
- Debugger fallback collects multiple candidates and selects the strongest complete same-ID tree.
- Debugger fallback no longer receives `verified` completeness unless the authoritative endpoint can be identified and the parent chain is continuous.
- Capture diagnostics are retained in source metadata.

## Canonical normalization

- Added provider-neutral semantic message types.
- Classifies commentary/progress, tool calls, tool results, reasoning, system and developer events separately from final assistant answers.
- Converts text payloads of technical events into typed canonical content parts.
- Preserves a stable stream grouping hint.

## Rendering

- Compact mode includes only real user content and final assistant content.
- Assistant-only mode includes only final assistant content.
- Technical mode labels tool, reasoning and intermediate events and keeps technical details collapsed.
- Coalesces cumulative/delta fragments sharing a stable message identity.
- Counts messages after semantic filtering and coalescing.
- Replaced misleading completeness labels with verified/possible/failed/unverified language.

## Integrity

- Validates the current leaf-to-root parent chain.
- Verifies the normalized active path against the graph parent chain.
- Tracks semantic event counts, filtered technical events, parse failures and timestamps.
- Requires `source.completeness === verified` before returning `COMPLETE`.
- Active-branch unknown content prevents a complete label.

## Tests

Added regression coverage for:

- a 50-turn conversation without prior DOM scrolling;
- a small last-turn event package arriving before a complete same-ID tree;
- commentary, Skill/tool, search and reasoning events in compact mode;
- technical-mode categorization and default folding;
- cumulative streaming fragments;
- unverified sources and broken parent chains;
- authoritative API preference and fallback downgrade.
