# KV Archive v0.14.2 Changeset

## Added

- `packages/content-contract/src/index.ts`
  - provider-neutral editable content object contract;
  - immutable versions, typed relations, operation records and promotion drafts;
  - stable content evidence URI and exact revision/hash parsing.
- `apps/extension/src/capture-store.js`
  - IndexedDB and in-memory content stores;
  - create, update, version restore, archive, trash, relation and promotion workflows;
  - export of current objects plus version/log/relationship history.
- `apps/extension/src/capture.html`, `capture.css`, `capture.js`
  - Capture Center UI and independent Project filtering.
- Bundle v3 content files and read-only Agent/MCP content interfaces.
- Content graph/Obsidian integration and notes-only Project export.
- Automated content-contract, Bundle compatibility, MCP, Context Pack and graph tests.

## Changed

- IndexedDB schema version 10 → 11.
- Popup and full-page navigation expose Capture Center.
- Project State evidence verification accepts exact `contextvault://content/...` evidence.
- Agent Bundle manifest and integrity hash include content objects, versions, relations, operations and promotions.
- Knowledge graph compiler accepts editable content while preserving immutable conversation evidence.
- Obsidian exporter groups unified content under `70 Content`.
- Root, extension and Agent Bridge versions advance to 0.14.2.

## Compatibility

- Raw Evidence `content-objects` payloads are not rewritten.
- Existing Project State schema and Evidence URIs remain valid.
- Agent Bundle v1/v2 remains readable.
- Existing conversation-only Obsidian exports remain supported.
- Promotion creates review artifacts; it does not silently mutate approved state.

## Explicitly not included

- direct Capture Package import/recovery;
- cross-device sync or conflict replication;
- OS Share Target / Capture Inbox;
- mobile PWA;
- provider-specific Gemini/DeepSeek capture;
- guaranteed original Voice audio preservation.
