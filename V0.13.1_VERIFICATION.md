# KV Archive v0.13.1 Verification

Status: `LOCALLY_VERIFIED`

This record covers the Multi-Provider Foundation and Conversation Basket implementation on top of v0.13.0. It does not claim real logged-in browser acceptance, remote CI, or production release.

## Verified scope

- Canonical Schema v0.2 with provider, capture-mode and collection fields.
- Legacy v0.1 conversation migration without losing `projectId` compatibility.
- Known-provider detection and broad-domain conversation URL gating.
- Generic visible-only snapshots normalized into a valid partial Canonical graph.
- ChatGPT ordinary, archived and Project catalogs merged into stable selectable references.
- Selection-set deduplication, filtering, persistence contract and stable job identity.
- Selected-conversation tasks fetch only chosen conversation IDs and skip account-wide indexing.
- Selected export resumes through the existing durable history store and low-memory archive pipeline.
- IndexedDB version 9 creates the selection store without removing existing stores.
- Existing backup, library, Memory, Project State, Obsidian, scheduling, Agent Bridge and Continuity Benchmark regressions remain covered.

## Defects found during verification

- Initial release assertions still expected v0.13.0 and Schema v0.1; updated to the intentional v0.13.1/v0.2 contracts.
- Generic DOM candidate filtering originally deduplicated separate messages with identical text; changed to structural DOM containment deduplication so repeated message content is preserved.
- Broad `x.com` provider detection could have treated ordinary X pages as Grok; added conversation URL gating.
- Unknown pages had no explicit generic-mode path; added user-confirmed generic visible capture.
