# Security Policy

KV Archive handles potentially private AI work history. Security/privacy bugs involving credential persistence, cross-project leakage, destructive data loss, unexpected remote upload or access to unrelated origin storage should be treated as high priority.

Do not post real tokens, cookies, private conversation exports or browser-profile databases in a public issue. Once the GitHub repository exists, prefer GitHub private security advisories for sensitive reports when available.

The deterministic/local-first core should not send user content to an external model or service unless the user explicitly enables that behavior.
