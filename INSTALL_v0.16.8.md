# Install KV Archive v0.16.8

1. Close open KV Archive pages.
2. Extract `KV-Archive-v0.16.8-extension-install.zip`.
3. To preserve current browser data, overwrite the files in the folder already loaded by Chrome, keeping the same folder path.
4. Open `chrome://extensions` and click Reload.
5. Confirm version `0.16.8`.

For a clean install, remove the old extension and load the extracted folder containing `manifest.json` directly.
