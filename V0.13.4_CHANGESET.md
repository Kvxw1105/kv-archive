# KV Archive v0.13.4 Changeset

## Structured capture confidence

- Added `assessStructuredCaptureConfidence()`.
- Added page-probe comparison against visible-message and stable-turn lower bounds.
- Added small-branch corroboration requirement.
- Added current-node/current-message diagnostics.
- Added `hydrationCorroboratesStructuredCapture()`.
- Prevented small self-consistent response trees from being labelled verified without corroboration.

## DOM history hydration

- Added scored conversation-scroll-container selection.
- Penalized navigation and sidebar containers.
- Locked the selected scroller unless it becomes unusable.
- Added explicit completion outcomes: complete, time-limit, step-limit and stalled.
- Added bounded dynamic step calculation and duration limits.
- Added stable-at-top confirmation rounds.
- Added visible hydration progress.
- Preserved distance from the bottom when restoring the reading position.
- Recorded scroller switches, sizes, positions, duration and stable turn bounds.

## Virtualization and merge correctness

- Deferred role parity inference until after all virtualized windows are merged.
- Preserved repeated content from different stable turns.
- Separated progress-observation keys from final merge keys.
- Prevented viewport-index changes from appearing as newly discovered history.

## Export selection and diagnostics

- Structured normalization failure can fall back to hydrated DOM evidence.
- Larger hydrated readable branches can replace uncertain smaller structured branches.
- Incomplete hydration produces an explicit warning and cannot claim completeness.
- A→D diagnostics now include capture source, completeness, hydration outcome, iteration count, page lower bound and confidence reason codes.
- Corrected hydration iteration field propagation.
- Added a regression assertion that one requested export produces one download call.

## Tests

Added or expanded regression coverage for:

- small continuous but incomplete structured trees;
- large continuous structured trees;
- completed versus incomplete hydration corroboration;
- role-less virtualized windows;
- scroll restoration after viewport-size changes;
- conservative stable turn parsing;
- single-download behavior;
- hydration diagnostic propagation.
