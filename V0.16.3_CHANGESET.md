# KV Archive v0.16.3 Changeset

- Added `resolveExportTitle()` for current-conversation downloads.
- Current HTML, Markdown and ZIP exports prefer the real conversation title.
- Provider suffixes such as `- ChatGPT`, `| Claude` and `· Gemini` are removed from page-title fallbacks.
- Generic titles such as `ChatGPT`, `New chat`, `未命名对话` and `网页 AI 对话` no longer become final filenames when a first user message is available.
- Added deterministic first-user-message and conversation-ID fallbacks.
- Hardened filename sanitization for Windows-forbidden characters, trailing periods/spaces and reserved device names.
- No database migration and no export-content format change.
