# KV Archive v0.16.2 Changeset

## Added

- `history-export-snapshot.js` for read-only partial export snapshots.
- Capture/Export pipeline UI, pause, export-saved and new-batch controls.
- Durable task counters and partial archive progress metadata.
- Chunked catalog and selected-list rendering.
- Per-conversation timeout and selected-batch retry ceiling.

## Changed

- Selected conversation capture no longer automatically creates ZIP files.
- Export now reads only browser-local durable artifacts.
- Pause requests stop subsequent retries after the current request settles.
- Partial archive filenames include saved/selected progress.
- Response body parsing remains inside the request timeout boundary.

## Preserved

- Existing evidence, history jobs and stored artifacts.
- Resume behavior and failed-item retry.
- Low-memory volume generation.
- Existing archive readers and all other KV Archive subsystems.
