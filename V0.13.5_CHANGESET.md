# KV Archive v0.13.5 Changeset

## Scope

Preserve ChatGPT Voice / Live transcript turns as readable conversation messages in compact and technical exports without leaking audio metadata into the readable layer.

## Runtime changes

### Domain

- Added `user_voice_transcript` and `assistant_voice_transcript` canonical semantic types.

### Normalizer

- Added structured Voice/realtime signal detection.
- Added transcript extraction across snake_case, camelCase and nested `parts` shapes.
- Mapped user and assistant transcripts to canonical text content.
- Added Voice transcript provenance metadata.
- Kept tool and reasoning classification ahead of Voice classification.
- Rejected audio-only messages without readable transcript text.

### DOM adapter

- Unioned ordinary and Voice/transcript selector families.
- Added Voice/audio/transcript candidate selectors.
- Added message-container normalization and Voice marker detection.
- Preferred transcript descendants and removed control/media nodes from fallback text.
- Inferred canonical role from Voice semantic type before parity fallback.

### Integrity

- Counted Voice user turns as user messages.
- Counted Voice assistant turns as final assistant messages.
- Added separate Voice transcript counters.
- Included Voice transcript types in renderable-conversation validation.

### Renderer

- Included both Voice transcript types in compact and assistant-only filtering.
- Mapped Voice turns to ordinary user/assistant labels.
- Added `语音转录` badge in technical mode only.
- Included user Voice turns in the HTML question directory.
- Added Voice transcript counts to A→D diagnostics.

### Extension pipeline

- Passed Voice counters from integrity reports into export diagnostics.

## Tests added

- Mixed ordinary text and Voice/Live transcript normalization.
- Compact HTML keeps transcripts and excludes audio URL / asset metadata.
- Technical HTML labels transcripts without exposing media URLs.
- Integrity counts user and assistant Voice turns correctly.
- Unknown-role visible snapshots infer roles from Voice semantics.
- Dedicated Voice/transcript DOM selector coverage.
- Nested transcript variants and audio-only rejection.
- Voice streaming-fragment coalescing.
- Voice counts in A→D diagnostics.

## Protected behavior

- Compact mode continues to exclude tool, Skill, search, reasoning and commentary events.
- Different turns with repeated text remain distinct when stable IDs exist.
- Low-memory historical backup remains single-read bounded.
- Legacy Schema v0.1 and `projectId` remain readable.
- Raw evidence and audio metadata are not rewritten or deleted.
