# Install KV Archive v0.16.1

1. Unzip `KV-Archive-v0.16.1-extension-install.zip` into a permanent folder.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Disable the old KV Archive temporarily; do not delete its old folder yet.
5. Click **Load unpacked** and choose the unzipped folder containing `manifest.json`.
6. Confirm the extension page shows version `0.16.1`.

Rollback: disable v0.16.1 and re-enable/load the previous extension folder. Browser-local data is not intentionally cleared by this upgrade.
