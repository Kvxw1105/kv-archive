WHAT THIS DOES

这不是 ChatGPT 官方“记忆同步”

这里做的是本地上下文整理：选定一个 Project，只读取这个范围里的已确认状态和证据，再生成可复制、可插入或可导出的内容包。

Project 是什么，为什么需要选择？

Project 就是本地工作范围。同一项目的会话、笔记、决策、任务和证据会放在一起。强制限定范围，是为了防止把不同项目的信息混给 AI。

Project 可以来自 ChatGPT Project 会话，也可以来自记录中心中带有 Project 的笔记。若只有一个 Project，页面会自动选择；多次打开也会记住上次选择。
