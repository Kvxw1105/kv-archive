REFERENCE / CAPABILITY当前备份与快照能力展开技术范围 ＋
  • 普通历史与归档会话的独立分页闭合
  • Projects 列表和每个 Project 的游标分页
  • 个人空间与 Team／工作空间临时授权上下文
  • 旧任务原地迁移，不重复已保存内容
  • 用户上传文件、图片、DALL-E、代码解释器输出和 Project 文件
  • 相同 fileId 全局去重，只保存一次，多个会话共享引用
  • 附件大小与 SHA-256 校验、失败隔离和单独重试
  • 约 12–24 MB 低内存分卷，每卷写盘后再处理下一卷
  • 采集与打包分离，意外关闭后可继续剩余分卷
  • 暂停、继续、登录失效保护和旧任务迁移
  • 完成后可直接加入本地资料库
  • 每天、每 3 天、每周或每 30 天自动增量扫描
  • 会话与附件二进制的 SHA-256 内容寻址
  • 逻辑快照记录新增、更新、移除和未变化项
  • 快照保留策略和无引用对象回收

全量采集完成后不会自动打包。点击“生成低内存备份分卷”后，系统一次只构建并下载一卷，写盘完成后立即释放内存。当前单个附件安全上限会按设备内存设为 16–32 MB。
