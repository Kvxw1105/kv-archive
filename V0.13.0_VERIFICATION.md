# KV Archive v0.13.0 Verification

Status: `LOCALLY_VERIFIED`

This verification record covers the Continuity Benchmark implementation added on top of the user-supplied v0.12.2 source package. It does not claim real Chrome login-state acceptance, remote CI, or production release.

## Verified scope

- Deterministic Continuity Benchmark challenge generation from an Agent Bundle and approved Project State.
- Private answer key separated from the public challenge and receiving-Agent prompt.
- Structured response scoring across project identity, current status, active decisions, open tasks, blockers/next actions, and evidence citations.
- Critical fail gates for wrong Project ID, unsupported Decision IDs, unsupported Task IDs, and invalid `contextvault://` evidence URIs.
- CLI workflows for creating and scoring benchmarks.
- Agent Bridge packaging for Windows and POSIX shells.
- Agent Bundle guide and capability marker.
- Version consistency across the root package, extension manifest, extension build, and Agent Bridge package.

## Regression defect found and fixed

The first implementation allowed a perfect response to score `103.5/100` because the decision-record correctness formula counted an extra priority component. The scoring formula was corrected, a perfect-response regression assertion now requires exactly `100/100`, and the final total is defensively clamped to the `[0, 100]` range.
