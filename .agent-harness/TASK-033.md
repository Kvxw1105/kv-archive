# TASK-033 — ChatGPT 导入与资料库改版

状态：实现已在独立工作树通过本地合成验收；安装态与实包未验。

## 实现范围

- `previewImportArchives` 只读输入文件，不接收数据库。按文件、可定位的 ZIP 条目、记录分别计数；只有明确调用 `commitImportPlan` 才入库。一个被确认的预检对象只能执行一次。
- `commitImportPlan` 将输入文件名、SHA-256、分卷和记录序号、写入结果写成可导出的 JSON 回执。可读记录数 = 预检拒绝 + 新增 + 更新 + 重复 + 旧版 + 写入失败。打不开的文件或条目另计，不伪造里面的记录数。回执不能落库时 UI 仍可导出并说明原因。
- 识别同一 ZIP 内独立会话 JSON，坏 JSON 或单条 CRC 失败时保留其他可读条目；无法解析 ZIP 目录时只拒绝该 ZIP。与导入无关的 ZIP 条目不解压、计入未导入。原始会话证据仍保存，附件实体和非会话数据不写入；官方导入不标作完整性已验证。
- 官方来源更新同 ID 会话不覆盖原有项目分类；写入当前索引与消息分类前使用同一个数据库事务。证据不因重复导入被改写。复用 v13 的原有库表和 Evidence URI，不迁移，不改变 Project State、PWA 或扩展权限。
- 资料库是本轮首个改版面。根据花叔设计中文适配版的视觉语法，精力集中在一个真实任务：水绿／石墨底的「导入台」突出唯一主动作，搜索和列表保持安静，异常逐文件展开，附属操作渐进披露。沿用原项目图标，主视觉是跟回执呼应的校对纸张；不使用外链素材。动效用于开场、拖拽和控件反馈，支持减少动态效果。其他主页面不在本轮改版范围。

## 观察到的检查

- `npm ci`、`npm run typecheck`、`npm test`（311/311）与七项既有性能脚本通过。本轮加六个定向回归，其中一个防止新版原生 File 的 `bytes()` 方法被误当作已读取数据。
- 同一合成批次：预检读到 3 条，2 条可导入、1 条异常，另有 2 个坏的文件或条目；核对数据库计数不变。提交后 1 新增、1 更新，已知项目未丢；重导 1 计为重复。
- 另用进程内模拟 IndexedDB 跑生产存储适配器：跨实例读回回执，两个并行重导各报告 1 重复，原项目可过滤检索。用模拟 DOM 驱动正式页面控件，验证预检、确认、回执 JSON 导出和重新挂载回读。辅助依赖仅装入隔离验证目录，未进入产品依赖。
- 同一合成输入对照 BASELINE/MODIFIED/ROLLBACK；独立副本回滚后文件 SHA-256 与原版相同、stdout 完全一致，补丁再次应用后逐文件匹配候选。
- 官方桌面内置浏览器和 Chrome 后端均在网络策略握手处失败。模拟 DOM 不算真实浏览器的渲染、窄屏或扩展安装验收。未安装、重载、访问任何真实资料库或登录态。
