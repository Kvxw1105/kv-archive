# Install KV Archive v0.16.6

## Clean installation

1. Unzip `KV-Archive-v0.16.6-extension-install.zip`.
2. Open `chrome://extensions`.
3. Enable Developer mode.
4. Choose **Load unpacked**.
5. Select the folder whose root directly contains `manifest.json`.
6. Confirm version `0.16.6`.

## In-place upgrade with local data retained

1. Close open KV Archive pages.
2. Copy the currently loaded extension folder as a rollback backup.
3. Replace the files inside the current loaded folder with v0.16.6 files; keep the folder path unchanged.
4. Click **Reload** in `chrome://extensions`.
5. Confirm version `0.16.6`.

## Theme use

- Full workspace: use the Appearance control near the bottom of the left rail.
- Popup: use the compact Auto / Light / Dark control below the brand header.
- **Auto** follows the operating system.
- The choice is local to this browser profile and is shared across KV Archive pages.
