# v0.16.0 Changeset

## Added

- `apps/pwa` phone-first Notes PWA.
- PWA manifest, icons, service worker and offline application shell.
- quick capture, timeline, search, filters, detail/edit dialogs and history restore.
- archive/trash/restore flows and bounded incremental timeline rendering.
- Portable Capture export/import/recovery UI compatible with the extension.
- `build:pwa`, `serve:pwa` and `test:pwa-performance` scripts.
- PWA unit/integration and performance tests.

## Changed

- root build now produces Core, extension, PWA and Agent Bridge.
- product/extension/Agent version references advanced to `0.16.0`.

## Preserved

- immutable Raw Evidence storage;
- approved Project State immutability;
- Portable Capture dry-run/conflict/receipt/rollback guarantees;
- Agent Bundle v1/v2/v3 compatibility;
- all existing capture, Voice/Live, Memory Gate, Obsidian and Verified Handoff behavior.
