# KV Archive v0.13.0 Changeset

This changeset records the intentional delta from the user-supplied v0.12.2 source package.

## Product behavior

- Added a deterministic Continuity Benchmark for validating whether a receiving Agent correctly understands a Project handoff.
- Added public challenge generation, private answer-key generation, a bounded response template, deterministic scoring, PASS/PARTIAL/FAIL verdicts, and Markdown reports.
- Added critical failure gates for wrong Project identity, invented Decision or Task IDs, and invalid evidence URIs.
- Added Agent Bridge CLI commands and Windows/POSIX launchers for benchmark creation and scoring.
- Added Continuity Benchmark guidance and a capability marker to exported Agent Bundles.
- Preserved `contextvault://` evidence URIs and the existing bundle format for backward compatibility while updating user-facing product identity to KV Archive.

## Compatibility and non-goals

- No existing backup database schema was migrated.
- No evidence object or approved Project State is modified by the benchmark.
- No browser UI for the benchmark was added in this slice.
- No remote model API is required, and the benchmark itself consumes zero model tokens.
- No Git commit, push, PR, CI, or deployment state is implied by this package.
